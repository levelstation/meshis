WAS IST MESHIS?

Dein Mesh hat jetzt
ein kleines Gegenüber.

Ein Meshi ist ein animierter Pixelbegleiter für dein Mesh-Gerät. Auf dem Home-Bildschirm zeigt er, was gerade passiert: ein empfangenes Paket, eine neue Nachricht oder ein Akku, der Aufmerksamkeit braucht.

Das Board-Menü bringt alle Figuren zusammen. Wähle deinen Favoriten mit dem Joystick aus. Renderer und Menücode werden auch im nativen macOS-Simulator verwendet – so lässt sich die Oberfläche ohne Flashen ausprobieren.

L1 Pro.

Entwickelt für den ursprünglichen Wio Tracker L1 Pro von Seeed Studio mit monochromem OLED.

Ein kompaktes Handgerät mit LoRa-Funk, Bluetooth, GNSS und eingebautem Akku. Das 128 × 64 Pixel große Display ist die Bühne für deinen Meshi.
